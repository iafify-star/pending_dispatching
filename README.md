# مراجعة شحن البالتات

واجهة عربية بطابع Noon Minutes لقراءة بيانات البالتات والتوت من Google Sheet، ثم التحقق من كل توت عند مسحه.

تحتوي الواجهة على زر للتبديل بين العربية والإنجليزية، وزر للتبديل بين الوضع النهاري والليلي. يتم حفظ الاختيارين على نفس الجهاز.

## التشغيل

افتح المجلد باستخدام VS Code وشغّل إضافة **Live Server**، أو من PowerShell نفّذ:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. يمكن أيضًا فتح `index.html` مباشرةً في المتصفح.

## مصدر البيانات

تُقرأ بيانات البالتات والتوت مباشرةً بصيغة CSV من تبويب `Sheet1` في [الشيت](https://docs.google.com/spreadsheets/d/1wx8Ps4-mTL9MpdbwV3FTv8gGEqwuQL_LisSoyUBu6ZU/edit?gid=0#gid=0). يجب أن يكون الشيت متاحًا للعرض لأي شخص لديه الرابط. يحتوي التبويب على العمودين `palletBarcode` و`containerBarcode`. يتم التحقق من تحديثات الشيت تلقائيًا كل 10 ثوانٍ، ويُعاد جلب البيانات فور رجوع الاتصال أو فتح تبويب الموقع، ويمكن التحديث يدويًا. هذا فحص دوري وليس بثًا لحظيًا لكل تغيير.

الصفوف المتكررة لنفس البالتة والتوت تُعرض مرة واحدة. عند فحص التوت، تُتجاهل لاحقة النسخة من شكل `_v22` في الشيت، لذلك يكفي مسح الكود الأساسي مثل `TGI64D09HAXEEG`.

إذا كان التوت الممسوح مسجلًا على بالتة أخرى، تعرض الواجهة البالتة والفرع وبيانات الشحن المتاحة له في الشيت. وإذا لم يكن الكود مسجلًا، تعرض تنبيهًا بأنه غير موجود.

تُراجع عمليات المسح داخل الواجهة فقط؛ لا تُضاف صفوف إلى الشيت. تتم مطابقة أكواد التوت دون لاحقة النسخة، وتعرض الواجهة البالتة والفرع وبيانات الشحن المسجلة عند مسح توت تابع لبالتة أخرى.
