# مراجعة شحن البالتات

واجهة عربية بطابع Noon Minutes لقراءة بيانات البالتات والتوت من Google Sheet، ثم التحقق من كل توت عند مسحه.

تحتوي الواجهة على زر للتبديل بين العربية والإنجليزية، وزر للتبديل بين الوضع النهاري والليلي. يتم حفظ الاختيارين على نفس الجهاز.

## التشغيل

افتح المجلد باستخدام VS Code وشغّل إضافة **Live Server**، أو من PowerShell نفّذ:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا تفتح `index.html` مباشرة باستخدام `file://` لأن المتصفح يمنع جلب بيانات الشيت في هذه الحالة.

## مصدر البيانات

تُقرأ البيانات من رابط تصدير CSV للشيت، ويُفترض أن يحتوي أول تبويب على العمودين `palletBarcode` و`containerBarcode`. يجب ضبط صلاحية الشيت على **أي شخص لديه الرابط - قارئ**. يتم التحديث تلقائيًا كل دقيقة، ويمكن التحديث يدويًا.

الصفوف المتكررة لنفس البالتة والتوت تُعرض مرة واحدة. عند فحص التوت، تُتجاهل لاحقة النسخة من شكل `_v22` في الشيت، لذلك يكفي مسح الكود الأساسي مثل `TGI64D09HAXEEG`. لا تُرسل الواجهة أي بيانات إلى الشيت؛ حالة المسح تبقى في جلسة الصفحة فقط.

إذا كان التوت الممسوح مسجلًا على بالتة أخرى، تعرض الواجهة البالتة والفرع وبيانات الشحن المتاحة له في الشيت. وإذا لم يكن الكود مسجلًا، تعرض تنبيهًا بأنه غير موجود.
